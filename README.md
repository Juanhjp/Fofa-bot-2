
# FOFA BOATE 2

Bot inteligente de WhatsApp.

## Comandos

- `!auto on` — ativa respostas automáticas.
- `!auto off` — desativa respostas automáticas.
- `!video LINK` — comando preparado para integração de vídeos.
- `!musica LINK` — comando preparado para integração de áudio.

## Instalação

Requer Node.js 20 ou superior.

1. Instale as dependências com `npm install`.
2. Configure as variáveis de ambiente.
3. Inicie com `npm start`.
4. Escaneie o QR Code com o WhatsApp do bot.

## Segurança

Não publique senhas, tokens, QR Codes ou arquivos de sessão.

A conexão utiliza Baileys, uma biblioteca não oficial do WhatsApp.

## Próximas funções

- Inteligência artificial.
- Recebimento e interpretação de áudios.
- Respostas em áudio com voz autorizada.
- Integração de downloads autorizados.
